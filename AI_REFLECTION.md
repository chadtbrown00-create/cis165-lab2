# AI Reflection

## Tools Used

I used ChatGPT to help me understand the lab instructions, create a basic starting point for the C++ programs, and explain the difference between integer division and using `double`.

## AI Decision

One prompt I used was asking why `double` should be used for the miles-per-gallon calculation. ChatGPT explained that dividing two integers can produce integer division, which removes the fractional part of the result. I used `double` for the miles, gallons, and MPG variables because the assigned calculation produces 19.5 MPG.

## Verification

I verified the programs by running them with the assigned values and with changed values. The sum program produced 150 using 50 and 100, and it produced 100 using 25 and 75. The MPG program produced 19.5 using 312 miles and 16 gallons, and 20.8333 using 250 miles and 12 gallons. These tests showed that the calculations and output matched my expected results.

## Learning

I learned how to store calculations in result variables before displaying them and why data types matter when performing division. I still need to practice writing C++ programs and understanding data types without relying on examples.
